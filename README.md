GO:PIANO Tweaks web app

https://superslonic.github.io/go-piano-tweaks

GO:PIANO Tweaks is a browser-based MIDI editor for the Roland GO:PIANO.

Features

• Access to over 1,400 built-in patches, including 30 drum kits, instead of just the 40 sounds available from the instrument's panel.

• Two independent parts

• Single Tone, Layer and Split modes

• Save up to 32 user presets directly to the instrument

• Mod Wheel for expressive real-time control

• USB and Bluetooth MIDI support

How to use

iPhone / iPad:

You’ll need the Web MIDI Browser app (free).
https://apps.apple.com/us/app/web-midi-browser/id953846217

In its settings, set up Bluetooth MIDI and turn on “Enable SysEx”.

Then open GO:PIANO Tweaks in Web MIDI Browser.

Android:

Simply open GO:PIANO Tweaks in Chrome.
